# Clothing Finder

Сайт, который по фото находит предметы одежды и ищет похожие товары в
интернет-магазинах (сейчас: Wildberries и Ozon, регион РФ).

## Как это работает

1. **Детекция** (`backend/detection.py`) — модель сегментации одежды
   (Segformer, `mattmdjaga/segformer_b2_clothes`) находит на фото предметы
   гардероба и их границы.
2. **Уточнение у пользователя** (`frontend/index.html`) — сайт показывает
   найденные предметы, пользователь выбирает, что искать, и регион поиска
   (РФ / весь мир).
3. **Визуальный поиск** (`backend/embeddings.py` + `backend/vectorstore.py`) —
   вырезанный фрагмент фото превращается в вектор через fashion-clip
   (`patrickjohncyh/fashion-clip`), похожие товары ищутся в векторной базе
   Qdrant (embedded-режим, без Docker).
4. **Каталог** (`backend/parsers/`, `backend/ingest.py`) — товары
   собираются парсерами магазинов и заранее загружаются в векторную базу.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Модели (Segformer, fashion-clip) скачаются автоматически при первом
запуске и закешируются в `~/.cache/huggingface` (~1–2 ГБ суммарно).

## Наполнение каталога

Каталог пустой, пока вы не запустите сбор товаров:

```bash
cd backend
python ingest.py
```

Это пройдётся по списку запросов (`QUERIES` в `ingest.py`), соберёт товары
с Wildberries и Ozon и посчитает для каждого эмбеддинг. Занимает время —
для Ozon используется headless-браузер (Selenium), это медленнее, чем
прямой запрос к API Wildberries. Запускайте регулярно (например по крону),
иначе цены и наличие в каталоге устареют.

## Запуск

```bash
cd backend
uvicorn main:app --reload --port 8000
```

Откройте `frontend/index.html` в браузере (или раздайте его любым
статическим сервером). Фронтенд обращается к API на `http://localhost:8000`.

## Эндпоинты API

- `POST /detect` — фото → список найденных предметов одежды (категория + bbox).
- `POST /search` — фото + bbox + категория + регион → похожие товары со ссылками.
- `GET /health` — статус сервиса и количество товаров в каталоге.

## Важно перед реальным использованием

1. **Легальность парсинга.** Перед запуском `ingest.py` в проде проверьте
   robots.txt и пользовательское соглашение каждого магазина — у части
   площадок явный запрет на автоматический сбор данных. Это юридический
   риск, а не только технический.
2. **Парсер Ozon хрупкий.** У Ozon нет открытого API, `backend/parsers/ozon.py`
   разбирает отрисованную JS-страницу через Selenium — при обновлении
   вёрстки сайта селекторы могут потребовать правки.
3. **"Весь мир" — пока заглушка.** Фильтр региона `world` в `vectorstore.py`
   просто снимает ограничение по региону; чтобы находить зарубежные товары,
   нужно добавить парсер под зарубежный магазин (ASOS/Zara/H&M и т.п.) и
   помечать его товары `region="world"` (или конкретной стране).
4. **Качество поиска = что напарсили.** Это не поиск "по всему интернету",
   а витрина из магазинов, которые вы подключили через `backend/parsers/`.
   Расширяйте список запросов в `ingest.py` и добавляйте новые парсеры по
   мере необходимости.
